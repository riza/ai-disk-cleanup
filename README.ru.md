# ai-disk-cleanup

**Освобождение места на диске с помощью ИИ-агента — с измерением, по уровням и с вашего одобрения.**

Проверенный на практике промпт, который превращает любой ИИ-агент (Claude Code, Cursor,
Codex, …) в аккуратного аудитора дискового пространства. Он проходит диск сверху вниз,
группирует находки по тому, насколько вы пожалеете об их удалении, и **ждёт вашего
одобрения, прежде чем что-либо тронуть**.

Работает на **macOS, Linux и Windows**.

## А почему не просто `du | sort` вручную?

Потому что самая крупная добыча редко лежит там, куда смотришь первым делом, а очевидные
цифры врут:

- `Docker.raw`, показывавший **60 ГБ**, на самом деле занимал **14 ГБ**. Удалять его,
  опираясь на видимый размер, значило бы построить отчёт на неверной цифре.
- Настоящим главным виновником оказался каталог на **23 ГБ** с мёртвыми `git` worktree от
  заброшенного рефакторинга — его не видит ни один чек-лист «почисти кэши».
- Два runtime симулятора iOS по **15 ГБ** для версий, которые уже никто не поддерживает,
  лежали в `/Library`, куда обычное сканирование домашнего каталога не добирается.

Промпт фиксирует метод, который это находит, и одновременно — ограждения, не дающие
слишком усердному агенту удалить ваш `.env`.

## Метод

1. **Определить ОС** — и использовать только команды и пути этой платформы.
2. **Измерять, а не угадывать** — спускаться до настоящего виновника, а не до его
   родительского каталога.
3. **Знать ловушки** — разрежённые диски, дважды посчитанные симлинки, снимки, удерживающие
   освободившееся место, асинхронные удаления, каталоги `target/`, не относящиеся к Rust.
4. **Отчитаться по трём уровням** — и остановиться:

   | Уровень | Что | Риск |
   |---|---|---|
   | 1 | Кэши, артефакты сборки, загрузки пакетов, мёртвые worktree | Восстановимо. Нет. |
   | 2 | Диски ВМ, старые runtime SDK, образы контейнеров | Реальные данные внутри исчезнут. |
   | 3 | Downloads, профили браузеров, неиспользуемые приложения | Полностью ваше решение. |

5. **Выполнять шаг за шагом** — печатая освободившееся место после каждого шага и
   используя собственную команду очистки каждого инструмента вместо `rm -rf`.
6. **Уважать границу привилегий** — всё, что требует `sudo` или повышения прав,
   возвращается вам готовой командой, а не обходится.
7. **Никогда не удалять** исходный код, историю git, `.env`, ключи, keychain, библиотеки
   фотографий и почты, папки облачной синхронизации, диски работающих ВМ и снимки ОС.
8. **Подвести итог** — включая то, что *вам* придётся исправить руками.

## Один реальный прогон

macOS, диск 494 ГБ, **заполнен на 99%, свободно 5,2 ГБ**:

| Шаг | Освобождено |
|---|---|
| Мёртвые worktree Claude/git в одном проекте | 4,9 ГБ |
| Каталоги `target/` у Rust | 5,7 ГБ |
| 83 × `node_modules` + кэши `.next` | 18 ГБ |
| `~/Library/Caches` (17 ГБ → 2,4 ГБ) | 14 ГБ |
| `~/.cache`, npm, modcache Go, Homebrew | 16 ГБ |
| Runtime симуляторов iOS 17.5 и 18.0 | 36 ГБ |
| Диск ВМ Docker Desktop | 14 ГБ |
| Диск ВМ OrbStack | 11 ГБ |
| Downloads: образ прошивки на 11 ГБ + 42 установщика | 14 ГБ |
| **Итого** | **≈111 ГБ** |

**С 5,2 ГБ до 117 ГБ свободного места. С 99% до 71%.** Два элемента, принадлежащих root
(кэш `dyld` симулятора на 10 ГБ и мёртвая установка Nessus на 6 ГБ), не были продавлены, а
возвращены в виде однострочных команд с `sudo` — ровно так, как требует промпт.

## Переводы

**Английская версия — эталон.** Если перевод расходится с
`prompts/disk-cleanup.en.md`, приоритет у английского. Меняя метод, сначала правьте
английский промпт, затем переносите изменение в остальные.

Новые переводы приветствуются: скопируйте `disk-cleanup.en.md`, оставьте все команды
оболочки ровно как есть, переведите только текст и назовите файл по коду BCP 47
(`disk-cleanup.<код>.md`). Добавьте соответствующий `README.<код>.md` и строку в таблицы
выше.

## Замечание о доверии

Промпт предписывает агенту считать всё найденное на диске **данными, а не инструкциями** —
имя файла или README внутри какой-нибудь скачанной папки не сможет убедить его удалить
больше. Он также запрещает обходить `sudo`. Прочитайте промпт перед запуском; он
намеренно короткий.
